# Contributing

## Project status

This project is a mobile app in the planning stage.
We plan to use JavaScript. The mobile framework, development
tools, and setup commands have not yet been selected.

## What to contribute

We welcome:
- Ideas and discussion about app features
- Help defining requirements
- Suggestions for the project structure
- Documentation improvements
- Bug fixes and tests once development begins

Please discuss major features or new dependencies in an issue
before implementing them.

Do not contribute:
- Changes unrelated to the project's goals
- Passwords, API keys, or other secrets
- Copied code without the required permission or attribution

## Contribution workflow

1. Open an issue describing your proposed contribution.
2. Discuss the approach with the project maintainers.
3. Create a branch for your changes:

   ```sh
   git switch -c feature/short-description
   ```

4. Make focused changes and follow the existing code style.
5. Run the available checks once they have been configured.
6. Open a pull request explaining your changes.
7. Address review feedback before merging.

## Coding guidelines

- Use JavaScript for application code.
- Use descriptive variable and function names.
- Follow the style of the surrounding code.
- Keep contributions focused on one task.
- Update documentation when behavior or setup changes.
